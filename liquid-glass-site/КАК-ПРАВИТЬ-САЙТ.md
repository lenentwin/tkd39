# Как править сайт через файл

> **Главное правило:** весь текст, цифры и фото сайта меняются **в одном файле** —
> `content/site.data.js`. В HTML и CSS заходить не нужно.
> Меняешь файл → сохраняешь → обновляешь страницу (F5) → сайт уже другой.

---

## 1. Как это устроено

`content/site.data.js` — это один большой объект `window.SITE = { ... }`. В нём:

- `theme` — палитра всего сайта;
- `brand` — название в шапке;
- `nav` — пункты верхнего меню;
- `sections` — **список блоков страницы** (самое главное);
- `footer` — подвал.

Порядок блоков на сайте = порядок объектов в массиве `sections`. Каждый блок — это
`{ id, kind, ...поля }`. Поле `kind` говорит движку, **каким** блоком его рисовать
(hero, features, medals и т.д.). Поле `id` — это `#якорь` для меню.

---

## 2. Как открыть и проверить

**Редактор:** открой `content/site.data.js` любым текстовым редактором
(Блокнот, VS Code, Notepad++). Достаточно этого файла.

**Посмотреть результат — 2 способа:**

1. Двойной клик по `index.html` → откроется в браузере. После правок обнови F5.
2. Через локальный сервер (надёжнее, без ограничений браузера на локальные файлы):

```
node tools/serve.js        →   http://localhost:5173
```

**Проверить, что нет ошибок** (полезно после большой правки):

```
node tools/smoke-test.js   # конфиг + рендер всех секций
node tools/verify.js       # ключевые данные и наличие фото
```

Если увидел `Ошибок: 0` — всё в порядке.

---

## 3. Правила синтаксиса (важно!)

Это **JavaScript**. Чтобы не получить сломанный сайт:

- Строки — в **двойных** кавычках: `"текст"`.
- Каждый объект `{ ... }` и каждый элемент массива заканчивается **запятой**, кроме последнего.
- Внутри строки **нельзя** ставить `"` без экранирования. Пиши так: `"клуб \"Тхэквондо\""`
  или используй кавычки-«ёлочки»: `"клуб «Тхэквондо»"` — так проще.
- Хочешь длинный текст — можно переносить на новую строку без кавычек, если соединить
  строки знаком `+`:

```js
subtitle:
  "Первая часть текста, " +
  "вторая часть текста.",
```

- Если что-то забыл — сайт покажет пустую страницу. Тогда открой консоль браузера (F12 →
  Console) — там будет написано, в какой строке ошибка. Чаще всего это **пропущенная запятая**.

## 4. Общие части

### Тема (цвета) — `theme`

```js
theme: "taekwondo",   // "aurora" | "sunset" | "mint" | "mono" | "taekwondo"
```

### Бренд (шапка) — `brand`

```js
brand: {
  name: "Центр развития",              // обычная часть лого
  accent: "тхэквондо МФТ",            // цветная (акцентная) часть лого
  tagline: "Федерация тхэквондо МФТ Калининградской области",
},
```

### Меню — `nav`

```js
nav: [
  { label: "О клубе",  href: "#features" },   // href = "#id" секции
  { label: "Тренер",   href: "#coach" },
  // ...добавляй/убирай строки
],
```

### Подвал — `footer`

```js
footer: {
  note: "© Центр развития тхэквондо МФТ, Калининград.",
  links: [
    { label: "Наверх", href: "#hero" },
  ],
},
```

## 5. Блоки страницы (массив `sections`)

Каждый блок — объект с полями. Ниже — все 12 типов, что уже стоят на сайте, и их поля.

### Общие поля почти любого блока

| Поле       | Что это                                  |
|------------|------------------------------------------|
| `id`       | якорь `#id` для ссылок в меню            |
| `kind`     | тип блока (см. таблицу ниже)             |
| `eyebrow`  | маленькая подпись над заголовком         |
| `title`    | заголовок блока                          |
| `subtitle` | поясняющий текст под заголовком          |

`eyebrow`, `title`, `subtitle` — необязательные: убрал — блок нарисуется без них.

Сводка типов:

| `kind`      | Что рисует                          | Ключевые поля           |
|-------------|-------------------------------------|-------------------------|
| `hero`      | большой первый экран                | title, subtitle, primaryCta, secondaryCta, badges |
| `features`  | сетка карточек-преимуществ          | items: icon, title, text |
| `stats`     | строка с цифрами (с анимацией)      | items: value, suffix, label |
| `medals`    | медальный зачёт + лента + полоски   | items, bars, awards     |
| `coach`     | блок о тренере                      | photo, name, role, facts, bio, quote |
| `gallery`   | сетка фото                          | items: img, title, caption |
| `locations` | карточки залов                      | items: name, address, hours, open |
| `reviews`   | отзывы                              | items: quote, author, role |
| `faq`       | вопрос-ответ (раскрывается)         | items: q, a             |
| `vk`        | плашка «Мы есть в VK»               | title, subtitle, label, href |
| `cta`       | призыв к действию                   | title, subtitle, primaryCta |
| `contact`   | контакты, телефон, почта, соцсети   | email, phone, socials   |

### 5.1 `hero` — первый экран

```js
{
  id: "hero",
  kind: "hero",
  eyebrow: "Тхэквондо МФТ · Калининград",
  title: "Школа тхэквондо, где растут чемпионы",
  subtitle: "Тренируем детей с 4 лет и взрослых. Первое занятие — бесплатно.",
  primaryCta:   { label: "Записаться",  href: "#contact" },   // главная кнопка
  secondaryCta: { label: "Достижения",  href: "#medals" },     // вторая кнопка
  badges: ["С 4 лет", "Бесплатное пробное", "Чёрные пояса"],
},
```

Хочешь только одну кнопку — просто удали строку `secondaryCta: {...},`.

---

### 5.2 `features` — преимущества (карточки)

```js
{
  id: "features",
  kind: "features",
  eyebrow: "О клубе",
  title: "Почему родители выбирают нас",
  subtitle: "Спорт, дисциплина и характер — в дружной команде.",
  items: [
    { icon: "🥋", title: "Дети от 4 лет", text: "Пробное занятие бесплатно." },
    { icon: "🏅", title: "Опыт 14 лет",   text: "Стабильно привозим медали." },
    // добавь новую карточку — просто вставь ещё одну строку { ... }
  ],
},
```

`icon` — это эмодзи (или можно убрать `icon` совсем, тогда карточка будет без значка).

---

### 5.3 `stats` — цифры со счётчиком

```js
{
  id: "stats",
  kind: "stats",
  items: [
    { value: 14, suffix: "+", label: "Лет работы федерации" },
    { value: 31, suffix: "",  label: "Медалей в Москве" },
    // value — число (анимируется от 0), suffix — то, что допишется после (напр. "+")
  ],
},
```

Внимание: `value` — **число без кавычек**, а `suffix` — **строка в кавычках**.

---

### 5.4 `medals` — достижения (3 части сразу)

```js
{
  id: "medals",
  kind: "medals",
  eyebrow: "Соревнования",
  title: "Наши победы и медали",
  subtitle: "...",

  // (1) Крупные цифры медалей
  items: [
    { tone: "gold",   icon: "🥇", value: 12, label: "Золото" },
    { tone: "silver", icon: "🥈", value: 10, label: "Серебро" },
    { tone: "bronze", icon: "🥉", value: 9,  label: "Бронза" },
  ],

  // (2) Полоски-проценты
  bars: [
    { tone: "gold",   label: "Доля золотых медалей",   pct: 39 },
    { tone: "silver", label: "Доля серебряных медалей", pct: 32 },
    { tone: "",       label: "Доля бронзовых медалей", pct: 29 },
  ],

  // (3) Лента соревнований по годам
  awards: [
    { year: "2024", title: "31 медаль в Москве", text: "Описание события." },
    { year: "2025", title: "Турнир в Ташкенте",  text: "Описание события." },
  ],
},
```

- `tone` задаёт цвет: `"gold"`, `"silver"`, `"bronze"` (для полоски можно оставить пустым `""`).
- `pct` — число 0–100.
- Любой из трёх кусков (`items` / `bars` / `awards`) можно удалить целиком, если он не нужен.

### 5.5 `coach` — блок о тренере

```js
{
  id: "coach",
  kind: "coach",
  eyebrow: "Наш тренер",
  title: "Иван Николаевич Миховский",
  subtitle: "Руководитель региональной федерации",
  photo: "assets/img/team-01.jpg",        // путь к фото (см. раздел 6)
  name: "Иван Николаевич Миховский",       // имя, показанное рядом с фото
  role: "Президент федерации, мастер спорта.",
  facts: [                                  // «чипсы» с фактами
    "🥋 Чёрный пояс (Дан)",
    "🏅 Мастер спорта",
    "📅 Стаж 14 лет",
  ],
  bio: [                                     // абзацы текста
    "Первый абзац биографии.",
    "Второй абзац биографии.",
  ],
  quote: "Мы открыли федерацию полностью с нуля.",   // цитата внизу
},
```

> Есть **два** поля с именем: `title` (заголовок раздела) и `name` (подпись у фото).
> Обычно их пишут одинаково. Убрал `quote:` — цитаты не будет.

### 5.6 `gallery` — фото

```js
{
  id: "gallery",
  kind: "gallery",
  eyebrow: "Фото",
  title: "Наша жизнь и победы",
  items: [
    { img: "assets/img/cover.jpg",     title: "Команда",     caption: "После турнира" },
    { img: "assets/img/training-01.jpg", title: "Тренировка", caption: "Техника" },
    // без поля img будет цветная плитка без фото
  ],
},
```

`title` — подпись крупно, `caption` — мелко. Убрал `img` — плитка станет просто цветной.

### 5.7 `locations` — залы

```js
{
  id: "locations",
  kind: "locations",
  eyebrow: "Где мы",
  title: "Адреса тренировочных залов",
  items: [
    { name: "Центр МФТ",     address: "ул. Генерала Челнокова, 43", hours: "Закрыто · откроется в 13:00", open: false },
    { name: "ТЦ Гиант",      address: "ТЦ Гиант",                   hours: "Откроется в 9:00",            open: false },
  ],
},
```

- `open: true` — зелёная точка «открыто», `open: false` — серая.
- Убрал `hours` — строки про часы не будет.

```js
{
```

```js
  kind: "contact",
  eyebrow: "Контакты",

  email: "tkd39ru@yandex.ru",
```

## 6. Как добавлять, убирать и переставлять блоки

**Убрать блок** — найди его объект в `sections` и удали целиком (от `{` до `},`), аккуратно
следя за запятыми.

**Переставить блок** — вырежи объект `{ ... },` и вставь в нужное место массива. Порядок в
файле = порядок на сайте.

**Добавить новый блок** — проще всего скопировать похожий существующий объект, вставить
рядом и поменять поля. Например, добавить ещё одну секцию с отзывами:

```js
{
  id: "reviews2",          // id должен быть уникальным
  kind: "reviews",
  eyebrow: "Отзывы-2",
  title: "Ещё отзывы",
  items: [
    { quote: "Новый отзыв.", author: "Ольга", role: "мама" },
  ],
},
```

⚠️ Важно: `id` у блоков **не должны повторяться**, иначе ссылки в меню будут вести не туда.

---

## 7. Как менять фото

1. Положи новые картинки в папку `assets/img/` (форматы `.jpg`, `.png`, `.webp`).
2. В `site.data.js` укажи путь **от корня сайта**, начиная с `assets/img/`:

```js
{ img: "assets/img/moe-foto.jpg", title: "Подпись", caption: "Мелкая подпись" },
```

Совет: имена файлов пиши латиницей, без пробелов (например `turnir-2025.jpg`), тогда точно
не будет проблем с путями.

## 8. Частые задачи (шпаргалка)

| Что хочу | Где менять |
|----------|-----------|
| Поменять телефон | `contact.phone` (и продублировать в `cta.primaryCta.href` и в тексте `faq`) |
| Поменять ссылку на VK | в блоках `vk.href`, `contact.socials`, а также в тексте `faq` |
| Поправить цифры медалей | блок `medals` → `items` и `bars` |
| Добавить соревнование в ленту | блок `medals` → `awards`, вставь `{ year, title, text }` |
| Сменить цвета всего сайта | поле `theme` (одно слово) |
| Убрать раздел «Отзывы» | удали объект с `kind: "reviews"` из `sections` |
| Добавить пункт меню | массив `nav`: `{ label: "Текст", href: "#id-блока" }` |
| Поменять фото тренера | `coach.photo` → путь к новой картинке |

## 9. Если что-то сломалось

1. **Страница пустая / блок пропал** — почти всегда пропущена или лишняя **запятая**.
2. Открой консоль браузера: **F12 → Console**. Там будет строка вида
   `Uncaught SyntaxError: ... site.data.js:120` — открой `site.data.js` на этой строке и проверь.
3. Быстрый контроль «на глаз»: запусти `node tools/smoke-test.js` — он скажет, если секция не
   рендерится.
4. Всегда можно **отменить** правку: `Ctrl + Z` в редакторе, до сохранения.
5. Держи резервную копию: перед большой правкой скопируй `site.data.js` в
   `site.data.backup.js` — если что, вернёшь как было.

Всё. Один файл — и весь сайт меняется. Удачи! 🥋
