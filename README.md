## Как менять контент (как конструктор)

📖 Подробная пошаговая инструкция со всеми полями: **[КАК-ПРАВИТЬ-САЙТ.md](КАК-ПРАВИТЬ-САЙТ.md)**

Коротко: открой `content/site.data.js`. Там всё описано по-русски. Ключевое:

- **Темы** — `theme: "aurora" | "sunset" | "mint" | "mono" | "taekwondo"`.
- **Меню** — массив `nav` (ссылки ведут к `#id` секций).
- **Секции** — массив `sections`. Порядок в массиве = порядок на странице.

Доступные типы секций (`kind`):

| kind        | Что это                                        |
|-------------|------------------------------------------------|
| `hero`      | первый экран                                   |
| `features`  | сетка карточек (преимущества)                  |
| `stats`     | строка с цифрами (с анимацией)                 |
| `medals`    | медальный зачёт + лента соревнований + полоски |
| `coach`     | блок о тренере (фото, факты, биография, цитата)|
| `gallery`   | галерея фото                                   |
| `locations` | залы / адреса                                  |
| `reviews`   | отзывы                                         |
| `faq`       | вопросы/ответы (раскрываются)                  |
| `vk`        | плашка «Мы есть в VK» (кликабельна)            |
| `cta`       | призыв к действию                              |
| `contact`   | контакты и соцсети                             |

После правок сохрани файл и обнови страницу.

> ⚠️ Цифры медалей (золото/серебро/бронза) в блоке `medals` — редактируемые.
> Достоверно из открытых источников известен **факт 31 медали** (Москва, 2024) и
> другие старты; распределение по достоинству — примерное, легко поменять под фактические данные.

## Как менять дизайн

- **Палитра целиком:** смени `theme` в `site.data.js` **или** отредактируй цвета
  `--c1/--c2/--c3` в `assets/css/theme.css`.
- **Светлая/тёмная:** переключатель в шапке (◐). Смена темы **плавная** (мягкие переходы +
  лёгкая вспышка, уважает `prefers-reduced-motion`). Выбор запоминается, плюс работает авторежим.
- **Радиусы, размытие, тени:** токены `--radius`, `--blur`, `--shadow` в начале `theme.css`.
