# Страница «Видео и контакты» (демо)

Отдельная страница, собранная **тем же движком и стилями**, что и основной сайт,
поэтому визуально выглядит как его часть.

- Папка самодостаточна: **исходные файлы сайта не изменялись.**
- Переиспользуются: `assets/css/theme.css`, `assets/css/styles.css`,
  `assets/js/render.js`, `assets/js/app.js` (подключаются по относительным путям).
- Свои файлы страницы: `index.html`, `site.data.js`, `video.js`, `page.css`.

## Как открыть

1. Через общий локальный сервер (рекомендуется), из корня проекта:

   ```
   node tools/serve.js
   ```

   Затем открой: http://localhost:5173/video/index.html

2. Или открой `video/index.html` двойным кликом (работает и без сервера).

## Что на странице

- Заголовок «Видео и контакты».
- Адаптивный YouTube-плеер (публичное демо-видео).
- Контактный блок — **вымышленные** телефон, e-mail, адрес, VK, Telegram.
- Инфо-блок «Мы в социальных сетях»: часы работы, короткое описание, кнопки связи.

> ⚠️ Все контакты на странице вымышленные и созданы только для демонстрации.
